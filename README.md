FCF - Fast Commandos Fix

Версия 8

Патч для исправления игры "Коммандос - тропа войны". Добавляет новые фишки и исправляет некоторые ошибки.

Новое:

* приветственное окно с информацией о патче;
* теперь по миникарте можно перемещаться кнопками WASD и стрелками;
* теперь колёсиком мыши можно двигать страницу как это делается ползунком;
* подробная информация о прохождении разного количества волн в выживании.

Вернулось:

* кнопка для покупки VIP-аккаунта;
* некоторые достижения.

Исправлено:

* опечатка в описании шахты "Счастливый квинт";
* курсор иногда пропадает во время боя;
* уведомление о том, что едут автобусы в мастерскую Джо, перенаправляет в другой магазин;
* невозможные задание и достижения;
* soft-lock из-за бага в коде.

Улучшено:

* оптимизация во время боя;
* общая оптимизация во время игры и при загрузке.
