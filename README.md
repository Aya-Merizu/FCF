* приветственное окно с информацией о патче;
* теперь по миникарте можно перемещаться кнопками WASD и стрелками.

Вернулось:

* кнопка для покупки VIP-аккаунта.

Исправлено:

* опечатка в описании шахты "Счастливый квинт";
* курсор иногда пропадает во время боя;
* уведомление о том, что едут автобусы в мастерскую Джо, перенаправляет в другой магазин.

Улучшено:

* оптимизация во время боя;
* общая оптимизация во время игры и при загрузке.
